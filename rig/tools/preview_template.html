Biscuit, up on its feet

Every animation below plays the original next to the new one, in step. Slow it down from the bar, or open any clip to scrub it frame by frame.

The rig, for the next mascots

One rule makes the animations reusable: a clip never contains a character's coordinates.

A clip only says things like arm R to wave_hi, sit, step with the left foot, face to joy. Each character decides what those words mean for its own body, so all 23 clips play on any mascot that defines them.

  1. Copy characters/biscuit.py and change the data: colours, joints, drawings, where the paws can reach, how long the legs are, the tail's shape.
  2. Register the new character and run python3 -m mascot.build --char name.
  3. Run tools/check.py and tools/handover.py. They flag player errors, pops, loop seams, anything that leaves the canvas, and clips that do not join up.
